# Countries

Countries app from the [Full Stack Open](https://fullstackopen.com/en/part2) course (Part 2). Search countries by name using the [RestCountries](https://restcountries.com/) API.

- Type in the search box to filter by country name.
- If there are too many matches, you’ll see a message asking to be more specific.
- If there are between 2 and 10 matches, a list is shown with a **show** button for each country to display its details (capital, area, languages, flag).
- If there is exactly one match, that country’s details are shown automatically.

## How to run

```bash
npm install
npm run dev
```

The app will be available at http://localhost:5173
